## 📖 About The Project

**NegaLauncher** is a custom, sleek Minecraft launcher designed to provide a smooth user experience, fast instance management, and full control over your game environment. Built natively using Windows Presentation Foundation (WPF), it features a custom borderless dark-themed UI inspired by modern desktop applications, integrated skin management, and advanced runtime configurations.

---

## ✨ Key Features

*   **Custom Modern UI:** Clean, borderless dark interface (`#1E1F22`) with custom window controls and smooth dragging.
*   **Skin Manager:** View your current player skin directly within the launcher, download it, or upload a new one (supporting both Classic and Slim/Alex models).
*   **Performance Tuning (GPU Selection):** Easily configure whether Minecraft runs on your integrated graphics or dedicated high-performance GPU (NVIDIA/AMD).
*   **Advanced RAM Allocation:** Interactive slider to allocate the exact amount of RAM required for smooth gameplay.
*   **Version Management:** Seamlessly select and switch between different Minecraft versions via a dedicated dropdown menu.
*   **In-App Console & Diagnostics:** Built-in live console output with options to view logs, close the console, or force-kill an unresponsive game instance.
*   **Quick Access:** One-click shortcuts to open the main game folder or access launcher settings.
